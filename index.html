// 01_about

Background

I'm a data engineer with a background in backend systems, which means I care about pipelines the same way I'd care about any production service: they sould be observable, they should fail loudly and recover quietly, and they should never silently drop a row.

Over the last few years I've moved from writing one-off scripts to designing systems — orchestrated batch jobs, streaming ingestion, warehouse modeling, and the monitoring that tells you when any of it breaks at 3am. I like the unglamorous parts of the job: schema design, backfills, idempotency, cost.

I'm currently working as a Data Engineering Consultant, developing expertise in cloud-native data engineering and data analytics. I am experienced in building secure, scalable ETL pipelines using Apache Spark, Delta Lake and Databricks, alongside data modelling, production-grade Python, Power BI and machine learning
